# Sorting Algorithm Visualizer

## 📌 Project Description

The **Sorting Algorithm Visualizer** is an interactive web-based application that demonstrates how different sorting algorithms work using visual representations of array elements. Each element is displayed as a vertical bar, and its height represents the value of that element.

The project helps users understand the working process of sorting algorithms through animations, color-coded bars, and adjustable visualization settings. Users can generate a random array, change the array size, adjust the sorting speed, and select different sorting algorithms to observe how elements are arranged in ascending order.

## ✨ Features

- **Interactive Visualization:** Displays array elements as vertical bars.
- **Generate New Array:** Creates a new random array for sorting.
- **Adjustable Array Size:** Allows users to control the number of elements.
- **Adjustable Sorting Speed:** Enables users to increase or decrease the animation speed.
- **Multiple Sorting Algorithms:** Supports Bubble Sort, Selection Sort, Insertion Sort, and Merge Sort.
- **Color-Coded Animation:** Highlights elements during comparisons, swaps, and sorting operations.
- **User-Friendly Interface:** Provides simple controls and an easy-to-understand visual layout.

## 🔢 Sorting Algorithms

### 1. Bubble Sort

Bubble Sort repeatedly compares adjacent elements and swaps them if they are in the wrong order. After each pass, the largest unsorted element moves to its correct position at the end of the array.

- **Best Time Complexity:** O(n), with an early-exit optimization.
- **Average Time Complexity:** O(n²).
- **Worst Time Complexity:** O(n²).
- **Space Complexity:** O(1).

### 2. Selection Sort

Selection Sort repeatedly finds the smallest element from the unsorted portion of the array and places it at the beginning of that portion. This process continues until the entire array is sorted.

- **Best Time Complexity:** O(n²).
- **Average Time Complexity:** O(n²).
- **Worst Time Complexity:** O(n²).
- **Space Complexity:** O(1).

### 3. Insertion Sort

Insertion Sort builds a sorted portion of the array one element at a time. It takes each new element and inserts it into its correct position among the previously sorted elements.

- **Best Time Complexity:** O(n).
- **Average Time Complexity:** O(n²).
- **Worst Time Complexity:** O(n²).
- **Space Complexity:** O(1).

### 4. Merge Sort

Merge Sort follows the divide-and-conquer approach. It divides the array into smaller subarrays, recursively sorts them, and merges the sorted subarrays to produce the final sorted array.

- **Best Time Complexity:** O(n log n).
- **Average Time Complexity:** O(n log n).
- **Worst Time Complexity:** O(n log n).
- **Space Complexity:** O(n) for a typical array-based implementation.
